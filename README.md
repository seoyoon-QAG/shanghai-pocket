# 상하이 포켓 v5 · 박은희 여사와 함께

접속 주소: https://seoyoon-qag.github.io/shanghai-pocket/

## 처음 한 번 연결

1. 기존 장소·처리 메모가 있는 기기에서 접속합니다.
2. 상단 **가족 연결 → 이 내용으로 가족 수첩 시작**을 누릅니다. 가족 중 한 명만 만드세요.
3. **초대 링크 복사**로 받은 링크를 가족에게 전달합니다.
4. 가족은 그 링크로 접속하면 같은 수첩에 참여합니다. 별도 회원가입은 없습니다.

일반 사이트 주소는 기본 목록을 여는 주소이고, `#family=…`가 있는 초대 링크는 가족 공용 수첩에 참여하는 주소입니다. 초대 링크를 받은 사람은 읽기와 편집이 모두 가능하므로 가족에게만 전달하세요. 실제 초대 링크는 GitHub 코드에 넣지 않습니다.

## 함께 저장하는 내용

- 새 장소·기존 장소 정보·중국어 주소·방문 날짜·순서
- 체크리스트 항목, 미완료/진행 중/완료, 담당자, 처리 메모
- 장소별 사진 최대 6장과 사진 설명
- 즐겨찾기·방문 여부

저장은 약 0.65초 뒤 전송하며, 화면이 열려 있고 인터넷이 연결되면 5초마다 다른 가족의 변경을 확인합니다. 입력 중인 칸이나 편집 창은 덮어쓰지 않고 입력을 마친 뒤 반영합니다. 동일한 항목의 서로 다른 메모/상태 필드는 함께 반영됩니다. 같은 필드를 동시에 다르게 고치면 **가족 연결**에서 어느 변경을 사용할지 선택합니다.

오프라인에서는 변경과 전송 대기를 해당 브라우저에 보관합니다. 다시 온라인이 되거나 페이지를 다시 열면 전송합니다. 브라우저 데이터 삭제·시크릿 모드 종료는 미전송 내용을 지울 수 있습니다. 사진 첨부는 온라인에서만 됩니다. 사진은 브라우저에서 최대 긴 변 1600px의 JPEG로 줄이고, 서버는 2MB 이하 JPG/PNG/WebP만 받습니다. 사진 메타데이터는 다시 인코딩한 파일로 대체됩니다.

사진은 **장소 편집 → 관련 사진 → 사진 첨부**에서 선택하고 설명을 적은 뒤 장소 **저장**을 누르세요. 업로드 후 장소 저장 전 취소한 사진은 공용 장소에 표시되지 않습니다.

## 자동 저장과 백업

가족 연결 전에는 이 기기에만 저장됩니다. 가족 연결 후에는 공용 저장소에 자동 반영되며 HTML·JSON 재업로드가 필요 없습니다. HTML·JSON 내보내기는 별도 백업용입니다. JSON 파일에는 사진 식별자와 설명이 들어가고 원본 이미지 파일은 포함되지 않습니다. 사진은 연결된 가족 수첩에서 불러옵니다.

연결 전 이 기기 내용은 브라우저에 별도 보관합니다. 가족 연결 해제 시 그 목록으로 돌아갑니다. 공용 내용을 삭제하는 기능은 아닙니다. 전송 대기나 충돌이 있으면 연결 해제를 먼저 하지 않습니다.

## 지도

Leaflet 1.9.4와 coordtransform 2.1.2를 HTML 안에 포함했습니다. Esri World Street Map 배경에는 인터넷 연결이 필요합니다. 고덕 GCJ-02 좌표를 배경 지도에 맞게 변환합니다. 핀·빈 곳·지역을 누르면 수첩에 등록된 장소만 반경으로 필터합니다. 주변의 모든 매장을 자동 수집하는 기능은 아닙니다. 직선거리이며 실제 길찾기는 고덕 링크를 사용합니다.

## 운영

- GitHub Pages: `main` / `(root)`.
- `index.html`, `family-sync.js`, `trip-features.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`가 함께 필요합니다.
- 여행 중 추가하는 내용은 GitHub 커밋이 아니라 별도 공용 데이터베이스와 파일 저장소에 보관됩니다.
- 배경 지도·고덕 연결과 공용 서버 연결은 중국 현지 통신망에서 별도 확인이 필요합니다. 목록과 주소는 캐시 준비 후 오프라인으로 볼 수 있습니다.
- 원래 장소 데이터와 확인 필요 경고는 유지했습니다. 영업시간·가격·예약은 실시간 조회가 아닙니다.
- 공개 HTML 백업에는 여권번호·카드정보 등 민감정보를 넣지 마세요.

기술 구조와 서버 수정 방법은 [FAMILY_SYNC.md](FAMILY_SYNC.md), 라이선스는 [THIRD_PARTY_LICENSES.txt](THIRD_PARTY_LICENSES.txt)를 참고하세요.

검증: 백엔드 SQL/가족 격리/사진 접근/동시 수정/재시도, 프런트 전송 대기/진행 중 수정/오프라인 보존, 실제 두 화면의 메모 반영과 사진 첨부 확인.


## v5 · 별점, 저장한 출처, 유연한 일정

상단에서 별점을 남길 이름을 선택하세요. 서윤·동생·박은희 여사 또는 추가한 이름마다 1~5점을 기록하며, 장소 카드에서 각자의 점수와 평균을 봅니다. 이름 선택은 기기별로 기억하고, 별점은 가족 수첩에 함께 저장합니다. 이름 선택은 인증 기능이 아니며, 기존 가족 초대 링크의 편집 권한을 그대로 사용합니다.

장소 편집의 ‘이 장소를 알게 된 출처’에 유튜브·인스타·기타 SNS 링크를 최대 8개 추가할 수 있습니다. 출처 이름과 URL을 저장하면 카드에서 바로 열립니다. 기존 기본 정보 출처는 유지합니다.

‘일차별 방문’에서 1D·2D로 장소를 배정합니다. 초기 4일차를 유지하고 최대 30일까지 추가할 수 있습니다. ‘일차 순서·전체 날짜 변경’에서 시작일을 바꾸면 전체 일차 날짜가 함께 바뀝니다. 날짜를 비우면 1D·2D만 표시됩니다. 일차를 위아래로 옮기거나 끌어 옮기면 안의 장소도 함께 이동합니다. 날짜와 표시 번호는 새 순서에 맞춰 계산되며 예약·항공권의 실제 날짜를 바꾸는 기능은 아닙니다.

한 일차에 담긴 장소를 다른 일차로 일괄 이동할 수 있습니다. 일차를 삭제하면 장소 데이터는 남고 미배정에서 볼 수 있습니다. 이전 날짜 ID로 배정했던 장소와 시각·메모도 유지합니다.

중국어 표현에 ‘맵지 않게’, ‘고수 빼 주세요’, ‘맵지 않게, 고수도 빼 주세요’를 추가했습니다. 버튼을 누르면 크게 보여 줍니다.
