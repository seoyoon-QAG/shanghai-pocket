# 상하이 포켓 v2 · 실제 지도 수정본

2026년 11월 6~9일 여행용. 설치·로그인·API 키 없이 사용하는 정적 HTML입니다.

## GitHub Pages에서 가족과 사용

1. GitHub에 로그인하고 새 **Public 저장소**를 만드세요. 이름 예: `shanghai-pocket`.
2. 이 ZIP을 압축 해제합니다. **폴더 자체가 아니라 안의 파일**을 저장소 루트에 업로드합니다. 최소한 `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg`를 함께 올리세요. `.nojekyll`도 넣을 수 있습니다.
3. 저장소의 **Settings → Pages**를 엽니다.
4. **Source: Deploy from a branch / Branch: main / Folder: /(root)** → **Save**.
5. 배포 후 GitHub Pages 화면에 나오는 사이트 주소를 복사해서 동생에게 보내세요. 저장소 주소가 아닌 Pages 주소입니다.
6. 각 휴대폰에서 열어 테스트하고, 가능하면 브라우저 메뉴의 ‘홈 화면에 추가’를 사용하세요. 기기·브라우저에 따라 앱 설치 옵션은 다를 수 있습니다.

현재 패키지에는 GitHub 계정 연결이나 실제 배포가 포함되지 않았습니다. GitHub가 발급하는 실제 Pages URL은 업로드 후 확인해야 합니다.

## 지도·주변 장소 (v2 수정)

- 이전 버전의 좌표 격자 화면을 **도로·강이 보이는 실제 지도**로 교체했습니다.
- Leaflet 1.9.4와 coordtransform 2.1.2 코드는 HTML 안에 포함했습니다. 지도 라이브러리 CDN을 별도로 불러오지 않습니다.
- 배경은 Esri 공개 World Street Map 타일 서비스입니다. 인터넷 연결이 필요하며 지도는 자동 오프라인 저장 대상에 포함하지 않습니다.
- 등록 좌표는 기존 고덕 GCJ-02를 그대로 보존하고, 배경 지도 표시 시 WGS84로 변환합니다. 지도에서 위치를 찍으면 다시 GCJ-02로 변환해 저장합니다. 변환은 근사값이므로 현지 출입구·하차 위치는 고덕에서 최종 확인하세요.
- 지도 핀·빈 곳·지역 버튼을 누르면 선택 지점 반경의 **내 수첩에 등록된 장소**만 목록에 표시됩니다. 주변의 모든 매장을 실시간으로 조회하는 기능은 아닙니다.
- 반경은 500m·1km·2km 버튼 또는 50~50,000m 직접 입력으로 바꿀 수 있습니다.
- 지도 이동·확대·축소와 휴대폰 두 손가락 확대를 지원합니다. 지도 이동만으로는 기준점을 바꾸지 않으며, 기준점은 직접 눌러 선택합니다.
- 거리는 직선거리입니다. 강을 건너는 실제 보행·차량 경로는 고덕에서 확인하세요.
- **고덕에서 열기**는 선택 지점을 고덕 지도 새 창·앱에서 여는 링크입니다. 표시가 불안정한 내장 고덕 화면은 기본 기능에 넣지 않았습니다.
- 타일 응답이 없거나 요청이 실패하면 지도 아래에 안내합니다. 브라우저·네트워크에 따라 지도 제공자가 차단될 수 있으며 중국 현지 통신망에서의 동작은 별도 확인이 필요합니다.
- 좌표가 없는 후보는 전체 목록에는 남고, 반경 검색에서는 제외됩니다.

## 현장에서 추가·수정

- **＋ 장소 추가**에서 이름·종류·지역·중국어 주소·메모·방문 날짜·시간·링크를 입력하세요.
- 좌표는 고덕 GCJ-02 위도·경도를 입력하거나, 편집 창의 지도에서 직접 지정합니다. 주소에서 좌표를 자동 변환하지 않습니다.
- 좌표 없이 저장해도 장소 목록·검색·주소 복사 기능은 작동합니다.
- 지도 링크가 없으면 중국어 이름+주소를 이용한 고덕 검색 링크를 생성합니다. 검색 결과의 실제 지점은 직접 확인하세요.
- 한국어 이름은 Google Maps 검색, 중국어 이름은 고덕 장소/검색으로 연결됩니다.
- 주소 복사가 지원되지 않으면 수동 복사 창이 열립니다.
- **크게 보기**는 기사님께 보여주기 위한 중국어 화면입니다. 디디 호출이나 목적지 자동 입력은 하지 않습니다.
- **내 순서** 정렬에서는 ≡ 손잡이를 끌거나 ↑↓ 버튼으로 순서를 바꿀 수 있습니다. 필터된 목록에서 옮기면 다른 항목의 상대 순서는 보존됩니다.
- 날짜별 방문 목록은 직접 배정합니다. 아직 예약증과 대조되지 않은 일정을 확정 일정으로 자동 입력하지 않았습니다.

## 자동 저장과 가족 공유의 차이

장소 수정·순서·즐겨찾기·방문 여부·체크리스트는 **해당 기기, 해당 브라우저의 localStorage**에 저장됩니다. 실시간 공동편집·서버 동기화 기능은 없습니다. 브라우저의 사이트 데이터 삭제·시크릿 모드 종료 등으로 사라질 수 있으니 백업하세요.

- 내 기기 보관: **저장·공유 → JSON 백업**.
- 다른 기기로 옮기기: JSON 파일을 전달한 뒤 **JSON 백업 가져오기**. 가져오기는 현재 기기 데이터를 대체하기 전 확인합니다.
- 가족 공통 기본 목록 갱신: **현재 내용을 담은 index.html 내려받기** → GitHub 저장소의 `index.html`을 교체 → 배포 완료 후 접속.
- 이미 이용하던 가족 기기는 localStorage의 수정 상태를 유지합니다. 새 기본 목록을 적용하려면 먼저 백업한 후 **내 기기 설정 지우기**를 누르세요.
- 내려받은 HTML에는 현재 장소·메모·순서·체크 상태가 들어갑니다. 공개 파일에는 여권번호·예약번호·카드정보 등 민감정보를 입력하지 마세요.
- 동시 수정 충돌을 피하려면 공통 HTML 업데이트 담당자를 한 명 정하는 게 편합니다.

## 오프라인

HTTPS 사이트에서 서비스 워커 캐시 준비가 완료된 뒤에는 캐시된 수첩 화면을 다시 열 수 있습니다. 브라우저가 저장 공간을 비우면 캐시가 없어질 수 있습니다. 지도 앱·길찾기·외부 정보 확인에는 인터넷 연결이 필요합니다.

출국 전에 나와 동생 휴대폰에서 실제 URL을 열고, 준비 탭의 ‘오프라인 캐시 준비 완료’를 확인하고, 비행기 모드로 다시 여는 연습을 해 보세요. GitHub Pages는 중국 현지 통신망에 따라 접속이 불안정할 수 있으므로 HTML 파일도 따로 내려받아 두세요. 휴대폰 로컬 HTML 열기는 파일 앱·브라우저 지원에 따라 다릅니다.

## 수정본으로 교체하기

이 채팅의 HTML 미리보기는 외부 지도 요청을 제한할 수 있으므로, 다운로드한 HTML을 브라우저에서 열거나 GitHub Pages의 HTTPS 주소로 접속하세요.
