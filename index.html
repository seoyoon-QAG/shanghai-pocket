가족이 함께 보는 수첩

상단 ‘가족 연결’에서 수첩을 한 번 만들고 초대 링크를 가족에게 보내 주세요. 같은 가족 수첩에 참여하면 장소·처리 메모·사진이 자동 저장됩니다.

인터넷이 연결되어 있으면 약 5초마다 새 내용을 확인해요. 오프라인 수정은 기기에 보관한 뒤 다시 전송합니다. 사진은 인터넷 연결 후 첨부해 주세요.

초대 링크를 아는 사람은 이 가족 수첩을 읽고 수정할 수 있으니 가족에게만 전달해 주세요.

통신이 끊겨도 주소는 준비.

주소·메모는 지도 배경 없이도 열 수 있어요. 실제 지도 배경을 불러오려면 인터넷이 필요해요. HTTPS로 접속 후 오프라인 캐시 준비가 완료되면 수첩 화면을 다시 열 수 있어요. 지도 앱·온라인 길찾기에는 인터넷이 필요해요.

GitHub Pages도 현지 통신망에 따라 접속이 불안정할 수 있으니, 출국 전에 각 휴대폰에서 열어 보고 HTML도 내려받아 두세요. 로컬 HTML 열기는 휴대폰 브라우저·파일 앱 지원에 따라 달라요.

저장·공유

가족 연결을 마치면 저장·수정 내용이 공용 수첩에 자동 반영돼요. HTML·JSON을 다시 업로드할 필요가 없어요. 아래 파일 내보내기는 별도 백업용입니다.

GitHub Pages에 올리는 순서

① 공개 저장소를 만들고 ZIP 안의 파일을 루트에 업로드
② Settings → Pages → Deploy from a branch
③ main / (root) 선택 → Save
④ GitHub가 보여주는 Pages 주소를 가족에게 전달
⑤ 수정 후에는 ‘현재 HTML 내려받기’로 받은 index.html을 같은 저장소에 덮어쓰기

HTML에 들어간 메모는 방문자가 볼 수 있어요. 공개할 파일에는 여권번호·예약번호·결제정보를 적지 마세요.
